# numfortune.uwp
A fortune teller in UWP for xbox

# The old fashion compiled way

Install Visual Studio 2022, download the project using GIT by selecting Download from Existing Git Repository and then compile it.

# How try it on Xbox
Go to https://developer.microsoft.com/it-it/microsoft-store/register/ and record your Hotmail account (possibly not the main one, but create a new one) as a Developer.
Pay the 17 euros, it is not clear whether a lotum or per year, and wait for the activation, then open on your second (not playing) Xbox One or Series X the App Store and download the Dev Kit app (the one with the Series s/x icons, not the one with the one icon), open it and follow the instructions on the video, paying attention to when it says "open windows 10 open, open aka.ms/quello_che_è and record the xbox), ad Open the "Xbox One Development Consoles" section from PC to your Developer Microsoft account, press the "+" button at the top right, select "Enter Activation Code" and indicate the code shown on the video; when the setting is over the console It is restarted and you enter the Developer Mode.

First record your Developer account in the appropriate section at the top right, then click on "Show Visual Studio Pin" and save it, now go to the PC, open the project, click on remote device instead of on the local computer when you have to Fill out, indicate the Xbox IP, wait for the pin to ask you, insert it and fill out.

Soon in the central lower section the numerone's fortune will appear, just start it to be able to play.
